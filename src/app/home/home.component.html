Datapod Project March 2025

In addition to the starter sites, I am starting new versions of Datapod projects in every combination of framework. So these are the most recent versions:

  • Datapod for Next.js - version 15, TypeScript/Tailwind, hosting at Vercel
  • Datapod for LERN One-Stack: repo
  • Datapod for LERN Split-Stack: frontend repo | backend repo
  • Datapod for MERN Split-Stack: frontend repo | backend repo
  • Datapod for React with JSON data source repo - This is a datapod template that has Zod validation of a JSON file set up with easy-peasy, but simply reads a JSON file. It's good to use as a base for Datapods that will have a parsing language to convert e.g. text files to JSON with "npm run dp". For example, this repo was used to make the datapod-for-react-go-json and datapod-for-react-python-json datapods.
