Project Datapod

A Datapod is a framework that can dynamically generate its own code files, has a self-contained data source, and makes working with data easy and flexible. I develop many Datapods in numerous technologies as a way to explore and learn various computer languages and frameworks. For more info, see my Datapod intro video.

Terminology

  • one-stack = used as a local app, started with one "npm run dev" command, but can be published at Vercel as an online, read-only site
  • split-stack = used as an online website, frontend on one server (e.g. Vercel), backend on another server (e.g. Hetzner), locally you have to start both frontend and backend with "npm run dev"
  • spawning project = an app that uses a Datapod for a real purpose, features that are built into this app to accomplish useful tasks are then ported into the Datapod framework
