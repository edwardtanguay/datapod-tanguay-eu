Welcome to Datapod Central. This is my central site which organizes all my work on the various Datapod frameworks that I am making in various technologies.

Take a look at the various starter sites, templates and datapods that i have created so far, and see my task board for my current development progress.

datapod project march 2025

in addition to the starter sites, I am starting new versions of datapod projects in every combination of framework, these are the most recent versions:

  • datapod for next.js one-stack: repo - version 15, typescript/tailwind, hosting at vercel
  • datapod for lern one-stack: repo
  • datapod for lern split-stack: frontend repo | backend repo
  • datapod for mern split-stack: frontend repo | backend repo
  • datapod for react-json one-stack repo - this is a datapod template that has zod validation of a json file set up with easy-peasy, but simply reads a json file. it's good to use as a base for datapods that will have a parsing language to convert e.g. text files to json with "npm run dp". for example, this repo was used to make the datapod-for-react-go-json and datapod-for-react-python-json datapods.
